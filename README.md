# AI-Assisted Physician Scheduling in Emergency Care

This repository contains the raw data associated with the study:

**Artificial intelligence-assisted physician scheduling in emergency care using demand forecasting and mixed integer programming**

The study examines the use of demand forecasting and mixed integer programming to support physician scheduling in emergency care.
